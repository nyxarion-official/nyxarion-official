PUBG Mobile

PUBG Mobile is a competitive battle royale game where 100 players drop onto an island and fight to survive. It focuses on strategy, weapon control, positioning, and teamwork. The game is widely popular in esports and ranked competitive play.

Wuthering Waves

A futuristic open-world action RPG set in Solaris-3. It features fast-paced combat, exploration, character switching mechanics, and a deep storyline focused on memory, identity, and survival.

GTA V

GTA V is an open-world crime action game set in Los Santos. It features missions, driving, character switching, and a massive online multiplayer mode with endless gameplay freedom.

Red Dead Redemption 2

RDR2 is a story-driven western adventure featuring realistic world systems, survival mechanics, and deep emotional storytelling set in the American frontier.
